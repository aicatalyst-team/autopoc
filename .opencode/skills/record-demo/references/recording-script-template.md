# Recording Script Template

This reference provides the complete structure for the Playwright recording
script that the LLM generates in Phase 2. The LLM customizes the
project-specific sections (marked with `{{ }}` placeholders).

## Complete Script Structure

```python
#!/usr/bin/env python3
"""
Demo video recorder for {{ project_name }}.

Records a side-by-side view of the OpenShift Console (Topology view)
and a web terminal running PoC sanity tests.

Generated by the record-demo skill. Do not edit manually.

Usage:
    python record.py

Output:
    demo.webm — recorded video (1920x1080, WebM/VP9)
"""

import json
import os
import signal
import subprocess
import sys
import time
from pathlib import Path

# ---------------------------------------------------------------------------
# Configuration (filled in by the LLM)
# ---------------------------------------------------------------------------

PROJECT_NAME = "{{ project_name }}"
NAMESPACE = "{{ namespace }}"
CONSOLE_URL = "{{ console_url }}"
TOPOLOGY_URL = f"{CONSOLE_URL}/topology/ns/{NAMESPACE}"

# Auth
IDP_NAME = os.environ.get("OPENSHIFT_IDP_NAME", "{{ idp_name }}")
CONSOLE_USERNAME = os.environ["OPENSHIFT_CONSOLE_USERNAME"]
CONSOLE_PASSWORD = os.environ["OPENSHIFT_CONSOLE_PASSWORD"]

# Paths
WORK_DIR = Path(os.environ.get("AUTOPOC_WORK_DIR", "/tmp/autopoc"))
OUTPUT_DIR = WORK_DIR / PROJECT_NAME / "demo"
VIDEO_PATH = OUTPUT_DIR / "demo.webm"

# Display
DISPLAY = ":99"
SCREEN_WIDTH = 1920
SCREEN_HEIGHT = 1080
WINDOW_WIDTH = SCREEN_WIDTH // 2  # 960
WINDOW_HEIGHT = SCREEN_HEIGHT

# Terminal
TTYD_PORT = 7681
TTYD_URL = f"http://localhost:{TTYD_PORT}"

# Timing
TOPOLOGY_PAUSE_SECONDS = 5       # How long to show topology before tests
FINAL_PAUSE_SECONDS = 5          # How long to show final state
RECORDING_TIMEOUT_SECONDS = 600  # Max recording duration (10 min)

# Test commands to run in the terminal
# The LLM fills these in based on poc-state.yaml
TEST_COMMANDS = [
    {{ test_commands }}
]

# Pattern to detect test completion in terminal output
COMPLETION_PATTERN = {{ completion_pattern }}  # e.g., r'"results"' or r'passed|failed'


# ---------------------------------------------------------------------------
# Infrastructure helpers
# ---------------------------------------------------------------------------

class InfraManager:
    """Manages background processes (Xvfb, ttyd, ffmpeg)."""

    def __init__(self):
        self.processes: dict[str, subprocess.Popen] = {}

    def start_xvfb(self):
        """Start Xvfb virtual display."""
        cmd = [
            "Xvfb", DISPLAY,
            "-screen", "0", f"{SCREEN_WIDTH}x{SCREEN_HEIGHT}x24",
            "-ac",  # Disable access control
            "+extension", "GLX",
        ]
        proc = subprocess.Popen(
            cmd, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL
        )
        self.processes["xvfb"] = proc
        os.environ["DISPLAY"] = DISPLAY
        time.sleep(1)  # Wait for Xvfb to initialize
        print(f"[infra] Xvfb started on display {DISPLAY} (pid={proc.pid})")

    def start_ttyd(self):
        """Start ttyd web terminal server."""
        cmd = [
            "ttyd",
            "-W",              # Writable (allow input)
            "-p", str(TTYD_PORT),
            "-t", "fontSize=16",
            "-t", "fontFamily=monospace",
            "bash",
        ]
        proc = subprocess.Popen(
            cmd, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL
        )
        self.processes["ttyd"] = proc
        time.sleep(2)  # Wait for ttyd to start listening
        print(f"[infra] ttyd started on port {TTYD_PORT} (pid={proc.pid})")

    def start_ffmpeg(self):
        """Start ffmpeg screen capture."""
        OUTPUT_DIR.mkdir(parents=True, exist_ok=True)
        cmd = [
            "ffmpeg",
            "-y",                           # Overwrite output
            "-f", "x11grab",                # X11 screen capture
            "-video_size", f"{SCREEN_WIDTH}x{SCREEN_HEIGHT}",
            "-framerate", "25",
            "-i", DISPLAY,                  # Capture from virtual display
            "-c:v", "libvpx-vp9",           # VP9 codec for WebM
            "-crf", "30",                   # Quality (lower = better, 30 is good)
            "-b:v", "0",                    # Variable bitrate with CRF
            "-pix_fmt", "yuv420p",
            str(VIDEO_PATH),
        ]
        proc = subprocess.Popen(
            cmd, stdin=subprocess.PIPE,
            stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL
        )
        self.processes["ffmpeg"] = proc
        time.sleep(1)
        print(f"[infra] ffmpeg recording started → {VIDEO_PATH} (pid={proc.pid})")

    def stop_ffmpeg(self):
        """Stop ffmpeg gracefully (send 'q' to stdin)."""
        proc = self.processes.get("ffmpeg")
        if proc and proc.poll() is None:
            try:
                proc.stdin.write(b"q")
                proc.stdin.flush()
                proc.wait(timeout=10)
                print("[infra] ffmpeg stopped gracefully")
            except Exception:
                proc.kill()
                print("[infra] ffmpeg force-killed")

    def cleanup(self):
        """Kill all background processes."""
        # Stop ffmpeg first (to finalize the video file)
        self.stop_ffmpeg()

        for name, proc in self.processes.items():
            if name == "ffmpeg":
                continue  # Already handled
            if proc.poll() is None:
                proc.terminate()
                try:
                    proc.wait(timeout=5)
                except subprocess.TimeoutExpired:
                    proc.kill()
                print(f"[infra] {name} stopped (pid={proc.pid})")


# ---------------------------------------------------------------------------
# Console login
# ---------------------------------------------------------------------------

def login_to_console(page):
    """
    Navigate to the OpenShift Console and log in via the configured IDP.

    Flow:
    1. Navigate to the console URL.
    2. Get redirected to the OAuth provider selection page.
    3. Click the IDP button matching IDP_NAME.
    4. Get redirected to the IDP login form (e.g., Keycloak).
    5. Fill in username/password and submit.
    6. Get redirected back to the console.
    """
    print(f"[auth] Navigating to {CONSOLE_URL}")
    page.goto(CONSOLE_URL, wait_until="networkidle", timeout=30000)

    # The console redirects to the OAuth page. Wait for the IDP button.
    print(f"[auth] Waiting for IDP selection page...")
    # OpenShift OAuth page lists identity providers as <a> or <button> elements.
    # The text content matches the IDP name configured in the cluster.
    idp_selector = f"a:has-text('{IDP_NAME}')"
    page.wait_for_selector(idp_selector, timeout=15000)
    print(f"[auth] Clicking IDP: {IDP_NAME}")
    page.click(idp_selector)

    # Now on the Keycloak (or other IDP) login page.
    # Wait for the login form to appear.
    print("[auth] Waiting for login form...")
    page.wait_for_selector("#username", timeout=15000)

    # Fill in credentials.
    page.fill("#username", CONSOLE_USERNAME)
    page.fill("#password", CONSOLE_PASSWORD)

    # Submit the form.
    # Keycloak uses #kc-login as the submit button ID.
    # Other IDPs may use input[type=submit] or button[type=submit].
    submit_selector = "#kc-login, input[type='submit'], button[type='submit']"
    page.click(submit_selector)

    # Wait for the console to load after redirect.
    print("[auth] Waiting for console to load...")
    page.wait_for_url(f"**{CONSOLE_URL.split('://', 1)[1]}/**", timeout=30000)
    # Wait for the page content to stabilize.
    page.wait_for_load_state("networkidle", timeout=30000)
    print("[auth] Login successful")


# ---------------------------------------------------------------------------
# Console navigation
# ---------------------------------------------------------------------------

def navigate_to_topology(page):
    """
    Navigate to the Developer Perspective Topology view for the PoC namespace.
    """
    print(f"[console] Navigating to topology: {TOPOLOGY_URL}")
    page.goto(TOPOLOGY_URL, wait_until="networkidle", timeout=30000)

    # Wait for the topology view to render.
    # The topology view uses an SVG canvas or a list view.
    # Wait for either the graph view or list view to appear.
    page.wait_for_selector(
        "[data-test='topology-graph-view'], "
        "[data-test='topology-list-view'], "
        ".odc-topology",
        timeout=30000,
    )
    print("[console] Topology view loaded")

    # Give the topology graph time to lay out and animate.
    time.sleep(3)


# ---------------------------------------------------------------------------
# Terminal interaction
# ---------------------------------------------------------------------------

def interact_with_terminal(page):
    """
    Navigate to the ttyd web terminal and run the PoC test commands.

    ttyd renders an xterm.js terminal in the browser. We interact with it
    by sending keyboard events, as if typing into the terminal.
    """
    print(f"[terminal] Navigating to {TTYD_URL}")
    page.goto(TTYD_URL, wait_until="networkidle", timeout=15000)

    # Wait for xterm.js to initialize.
    # ttyd's terminal container has class "xterm" when ready.
    page.wait_for_selector(".xterm-screen", timeout=10000)
    time.sleep(1)  # Let the terminal fully initialize

    # Click the terminal to focus it.
    page.click(".xterm-screen")
    time.sleep(0.5)

    print("[terminal] Terminal ready, executing test commands")

    for cmd in TEST_COMMANDS:
        print(f"[terminal] Running: {cmd}")
        # Type the command character by character (more realistic in video).
        page.keyboard.type(cmd, delay=30)  # 30ms between keystrokes
        page.keyboard.press("Enter")
        time.sleep(0.5)  # Brief pause between commands

    # Wait for tests to complete by watching for the completion pattern
    # in the terminal output.
    print(f"[terminal] Waiting for completion pattern: {COMPLETION_PATTERN}")
    # Poll the terminal's text content for the pattern.
    max_wait = RECORDING_TIMEOUT_SECONDS
    start = time.time()
    while time.time() - start < max_wait:
        # xterm.js renders text in rows. Get all visible text.
        try:
            text = page.evaluate("""
                () => {
                    const rows = document.querySelectorAll('.xterm-rows > div');
                    return Array.from(rows).map(r => r.textContent).join('\\n');
                }
            """)
            import re
            if re.search(COMPLETION_PATTERN, text):
                print("[terminal] Tests completed")
                break
        except Exception:
            pass
        time.sleep(2)
    else:
        print(f"[terminal] WARNING: Timed out after {max_wait}s waiting for completion")


# ---------------------------------------------------------------------------
# Main recording flow
# ---------------------------------------------------------------------------

def main():
    infra = InfraManager()

    try:
        # 1. Start infrastructure
        print("=" * 60)
        print(f"Recording demo video for {PROJECT_NAME}")
        print("=" * 60)

        infra.start_xvfb()
        infra.start_ttyd()

        # 2. Start screen recording
        infra.start_ffmpeg()

        # 3. Launch browser
        from playwright.sync_api import sync_playwright

        with sync_playwright() as p:
            browser = p.chromium.launch(
                headless=False,  # Must be visible on Xvfb
                args=[
                    f"--display={DISPLAY}",
                    "--no-sandbox",
                    "--disable-gpu",
                    "--disable-dev-shm-usage",
                    "--disable-extensions",
                ],
            )

            # 4. Create two browser windows (contexts with specific window positions)
            # Window 1 (left): OpenShift Console
            console_context = browser.new_context(
                viewport={"width": WINDOW_WIDTH, "height": WINDOW_HEIGHT},
                ignore_https_errors=True,
            )
            console_page = console_context.new_page()

            # Window 2 (right): ttyd terminal
            terminal_context = browser.new_context(
                viewport={"width": WINDOW_WIDTH, "height": WINDOW_HEIGHT},
            )
            terminal_page = terminal_context.new_page()

            # Position windows using CDP (Chrome DevTools Protocol)
            # This requires the browser to be launched with remote debugging.
            # Alternative: use window.moveTo() via page.evaluate()
            _position_windows(browser, console_page, terminal_page)

            # 5. Console: Login and navigate to topology
            login_to_console(console_page)
            navigate_to_topology(console_page)

            # 6. Pause on topology view
            print(f"[recording] Showing topology view for {TOPOLOGY_PAUSE_SECONDS}s")
            time.sleep(TOPOLOGY_PAUSE_SECONDS)

            # 7. Terminal: Run tests
            interact_with_terminal(terminal_page)

            # 8. Final pause — show both panes
            print(f"[recording] Final pause for {FINAL_PAUSE_SECONDS}s")
            time.sleep(FINAL_PAUSE_SECONDS)

            # 9. Clean up browser
            console_context.close()
            terminal_context.close()
            browser.close()

    finally:
        # 10. Stop recording and clean up
        infra.cleanup()

    # 11. Verify output
    if VIDEO_PATH.exists():
        size_mb = VIDEO_PATH.stat().st_size / (1024 * 1024)
        print(f"\n[done] Video saved: {VIDEO_PATH} ({size_mb:.1f} MB)")
        # Output machine-readable result
        print(json.dumps({
            "success": True,
            "video_path": str(VIDEO_PATH),
            "size_bytes": VIDEO_PATH.stat().st_size,
        }))
        sys.exit(0)
    else:
        print(f"\n[error] Video file not found: {VIDEO_PATH}")
        print(json.dumps({"success": False, "error": "Video file not created"}))
        sys.exit(1)


def _position_windows(browser, console_page, terminal_page):
    """
    Position two browser windows side-by-side on the virtual display.

    Uses Chrome DevTools Protocol (CDP) to set window bounds.
    Falls back to JavaScript window.moveTo/resizeTo if CDP is unavailable.
    """
    try:
        # Approach 1: Use CDP to set window bounds.
        # Each page belongs to a different browser context but the same browser.
        # CDP operates on "windows" which correspond to browser contexts.

        # Get the CDP session for each page.
        cdp_console = console_page.context.new_cdp_session(console_page)
        cdp_terminal = terminal_page.context.new_cdp_session(terminal_page)

        # Get current window IDs.
        console_window = cdp_console.send("Browser.getWindowForTarget")
        terminal_window = cdp_terminal.send("Browser.getWindowForTarget")

        # Position left window.
        cdp_console.send("Browser.setWindowBounds", {
            "windowId": console_window["windowId"],
            "bounds": {
                "left": 0, "top": 0,
                "width": WINDOW_WIDTH, "height": WINDOW_HEIGHT,
                "windowState": "normal",
            },
        })

        # Position right window.
        cdp_terminal.send("Browser.setWindowBounds", {
            "windowId": terminal_window["windowId"],
            "bounds": {
                "left": WINDOW_WIDTH, "top": 0,
                "width": WINDOW_WIDTH, "height": WINDOW_HEIGHT,
                "windowState": "normal",
            },
        })

        print("[layout] Windows positioned via CDP")

    except Exception as e:
        print(f"[layout] CDP positioning failed ({e}), using JS fallback")
        # Approach 2: JavaScript fallback.
        console_page.evaluate(
            f"window.moveTo(0, 0); window.resizeTo({WINDOW_WIDTH}, {WINDOW_HEIGHT})"
        )
        terminal_page.evaluate(
            f"window.moveTo({WINDOW_WIDTH}, 0); window.resizeTo({WINDOW_WIDTH}, {WINDOW_HEIGHT})"
        )


if __name__ == "__main__":
    main()
```

## Customization Guide for the LLM

When generating the script, the LLM MUST customize these sections:

### 1. Configuration Block

Fill in the project-specific values:

```python
PROJECT_NAME = "my-flask-app"
NAMESPACE = "poc-my-flask-app"
CONSOLE_URL = "https://console-openshift-console.apps.mycluster.example.com"
```

### 2. Test Commands

Based on `poc_execute.test_script_path` and `poc_execute.results` from
`poc-state.yaml`, generate the terminal commands. Typical patterns:

**For HTTP-based tests (services with routes):**
```python
TEST_COMMANDS = [
    "echo '=== Running PoC Sanity Tests ==='",
    "python /workspace/my-flask-app/poc_test.py http://my-flask-app-svc.poc-my-flask-app.svc:8080",
]
```

**For kubectl-based tests (jobs, CLI tools):**
```python
TEST_COMMANDS = [
    "echo '=== Running PoC Sanity Tests ==='",
    "kubectl get pods -n poc-my-flask-app",
    "kubectl logs -n poc-my-flask-app job/my-flask-app-test",
]
```

**For multi-step tests:**
```python
TEST_COMMANDS = [
    "echo '=== PoC Sanity Tests for my-ml-model ==='",
    "echo '--- Test 1: Health Check ---'",
    "curl -s http://my-ml-model-svc.poc-my-ml-model.svc:8080/health | python -m json.tool",
    "echo '--- Test 2: Inference ---'",
    "curl -s -X POST http://my-ml-model-svc.poc-my-ml-model.svc:8080/predict -H 'Content-Type: application/json' -d '{\"input\": [1,2,3]}' | python -m json.tool",
    "echo '--- All tests complete ---'",
]
```

### 3. Completion Pattern

Set `COMPLETION_PATTERN` to match the expected output when tests finish:

```python
# For poc_test.py output (JSON with "results" key):
COMPLETION_PATTERN = r'"results"'

# For simple echo-based completion:
COMPLETION_PATTERN = r'All tests complete'

# For pytest-style output:
COMPLETION_PATTERN = r'passed|failed|error'
```

### 4. Timing Adjustments

Adjust pauses based on test duration:

```python
TOPOLOGY_PAUSE_SECONDS = 5       # Show topology before tests start
FINAL_PAUSE_SECONDS = 5          # Show results at the end
RECORDING_TIMEOUT_SECONDS = 300  # Max 5 min for fast tests
```

## Error Handling Patterns

### Console Login Failure

If login fails, the script raises an exception. Common causes:
- Wrong `IDP_NAME` — the button text doesn't match.
- Wrong credentials.
- Console URL is wrong or unreachable.
- IDP (Keycloak) is down.

The `login_to_console` function has explicit timeouts on each step.

### Terminal Not Connecting

If ttyd doesn't start or the terminal doesn't respond:
- Check that port 7681 is available.
- Increase the sleep time after starting ttyd.
- Verify ttyd is installed in the container image.

### Test Timeout

If tests don't complete within `RECORDING_TIMEOUT_SECONDS`:
- The script prints a warning and continues.
- The video will show the terminal in its current state.
- The final pause still applies.

### ffmpeg Failure

If ffmpeg fails to capture:
- Verify Xvfb started successfully (`DISPLAY` is set).
- Check that the output directory is writable.
- Verify libvpx-vp9 codec is available (`ffmpeg -codecs | grep vp9`).

## Dependencies

The generated script requires these packages/binaries:

| Package | Install |
|---------|---------|
| `playwright` | `pip install playwright` |
| Chromium | `playwright install chromium` |
| `Xvfb` | `dnf install xorg-x11-server-Xvfb` |
| `ffmpeg` | `dnf install ffmpeg-free` (or install from static build) |
| `ttyd` | Download binary from GitHub releases |

All dependencies are pre-installed in the `autopoc-recorder` container image.
